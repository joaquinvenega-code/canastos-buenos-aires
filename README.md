# Landing – Canastos de Basura Buenos Aires

Versión funcional preliminar para validación del cliente.

## Archivos
- `index.html`: estructura y textos.
- `styles.css`: diseño responsive.
- `script.js`: menú móvil y enlaces de WhatsApp.
- `assets/`: imágenes tomadas del material suministrado por el cliente.

## Antes de publicar
1. Abrir `script.js` y reemplazar `54911XXXXXXXX` por el WhatsApp real en formato internacional.
2. Confirmar precios vigentes.
3. Reemplazar el recorte temporal del logo por el PNG original cuando esté disponible.
4. Confirmar dominio y datos comerciales definitivos.

## GitHub Pages
Esta carpeta es un sitio estático y puede publicarse directamente en GitHub Pages sin build.

## WordPress
Para la versión final se puede:
- recrear el diseño como plantilla/bloques en WordPress, o
- integrar este front-end en un tema hijo/plantilla personalizada.

La estructura fue pensada para que la migración sea directa: hero, modelos, beneficios, trabajos, FAQ y CTA.
